# Livvo

Rede social de leitura, em português, para quem quer registrar estantes, progresso e, nas versões seguintes, o convívio em torno dos livros. O nome é temporário.

A V0 é uma web responsiva para computador e celular. O aplicativo nativo fica para quando houver usuários.

O produto e os requisitos estão no [PRD](docs/prd.md). A issue de acompanhamento é a [#1](https://github.com/thaifurforo/Livvo/issues/1).
